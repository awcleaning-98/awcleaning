# Design System & UI Specifications

## 1. Brand Color Palette (Derived from AW Logo & Banner)
- **Primary Navy / Deep Blue**: `#043263` (Logo text, headers, primary buttons)[cite: 1, 2]
- **Vibrant Blue**: `#0072CE` (Gradient elements, highlights)[cite: 1, 2]
- **Water Cyan**: `#00B2FE` (Accents, sparkles, sub-headings)[cite: 1, 2]
- **WhatsApp Green**: `#25D366` (CTA buttons, phone direct actions)[cite: 1, 3]
- **Background Light**: `#F4F8FC` (Section backgrounds, card highlights)
- **Text Dark**: `#0F172A` (Body text for high contrast)

## 2. Typography
- **Primary Font**: `Inter`, `system-ui`, `-apple-system`, `BlinkMacSystemFont`
- **Headings**: Semi-bold to Extra-bold with slight gradient text support (`bg-clip-text`).

## 3. UI Component & Asset Details
- **Navbar**: Sticky white/glassmorphism header with AW Logo on left, navigation links centered (`Home`, `Our Services`, `Reviews`, `Contact Us`), and Green WhatsApp CTA button on right[cite: 1, 3].
- **Hero Section**:
  - Headline: "A Cleaner Home Feels Better!"[cite: 1]
  - Sub-headline: "Carpet Cleaning with AW Cleaning"[cite: 1, 2]
  - Key Selling Points Grid: "Licensed & Insured", "No Upfront Payments", "Pay Only If You're Happy"[cite: 1].
- **Preloader Screen**: Full-screen modal display featuring animated AW `.webp` logo transition[cite: 1, 2].
- **Before & After Gallery Component**: Interactive comparison cards displaying WebP images imported via code for fast rendering speed.
- **WhatsApp Screenshot Gallery**: Card layout featuring WebP screenshots of real customer feedback chats.
